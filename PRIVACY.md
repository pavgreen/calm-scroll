Privacy Policy for Calm Scroll

Last updated: 2026-09-09

Calm Scroll does not collect, store, or transmit any personal data or
browsing information. All image classification runs entirely on your
device, using a bundled machine learning model — no image, URL, or any
other data about the pages you visit is ever sent anywhere.

Specifically:

- The extension's settings (which categories are enabled, sensitivity
  level, on/off state) are saved locally on your device via Chrome's
  storage API and are never synced or transmitted off-device.
- Images are analyzed locally by an on-device model to decide whether to
  blur them. No image or image URL is sent to any server, including
  Google's or any other third party's.
- The extension makes no network requests at runtime. It does not use
  analytics, telemetry, cookies, or any third-party services.
- The extension requests broad host access (all websites) solely so it
  can find and classify images on any page you visit — this access is
  used only for that purpose and never to read, store, or transmit page
  content elsewhere.

If you have questions about this policy, please open an issue on the
project's repository.
